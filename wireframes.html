Add StockClaw to your AI client

  1. Open Claude → Settings → Connectors → Add custom connector

    https://mcp.stockclaw.example/mcp   [Copy]

    { "mcpServers": { "stockclaw": { "url": "https://mcp.stockclaw.example/mcp" } } }   [Copy]
  3. Sign in (OAuth) and approve scopes: read, trade (within agent key limits)

Pause agent Pausing revokes the key (confirmation required). Resume issues a new key with the same limits.

Revoke agent key
Your AI agent immediately loses the ability to trade. Open DCA/limit orders stop executing. Funds stay in your smart wallet.
Revoke agent key?
This signs one transaction. You can create a new key later.
✓ Revoked. Tx 0xMOCKREVOKE [explorer]. [Create new key]

UX notes

  1. 1. One-click revoke + confirmation dialog (focus trapped, Esc cancels, focus starts on Cancel).
  2. 2. Pause toggle = revoke under the hood (same confirmation); resume = re-issue. Key also auto-expires after 7 days.
  3. 3. Saving limits re-issues the key in one tx: stepper shows old revoked → new issued; failure leaves old key intact.
